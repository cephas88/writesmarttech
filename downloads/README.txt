INSTRUCTIONS FOR PREPARING EXTENSION DOWNLOADS
============================================

To make the extension downloads available on the WriteSmartTechnologies website, follow these steps:

1. PREPARING THE WRITEDOM BIDDING BOT:
---------------------------------------
a) Navigate to the "Writedom Bidding Bot" folder in your file system
b) Select all files in the folder
c) Create a ZIP archive named "writedom-bidding-bot.zip"
d) Place the ZIP file in this "downloads" directory

2. PREPARING THE WRITERSHUB BIDDING BOT:
----------------------------------------
a) Navigate to the "WritersHub Bidding Bot" folder in your file system
b) Select all files in the folder
c) Create a ZIP archive named "writershub-bidding-bot.zip"
d) Place the ZIP file in this "downloads" directory

3. VERIFYING THE DOWNLOADS:
---------------------------
a) Ensure both ZIP files are in this directory:
   - writedom-bidding-bot.zip
   - writershub-bidding-bot.zip
b) Verify that each ZIP file contains all necessary files for the extension to work
c) Test each ZIP by extracting and loading as an unpacked extension in Chrome

4. WEBSITE INTEGRATION:
----------------------
Once the ZIP files are prepared, the download buttons on the website will
automatically link to these files when the website is published.

Note: If you update the extensions, remember to replace these ZIP files with
the updated versions to ensure users always download the latest versions.
