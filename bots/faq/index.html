What is WriteSmart Bots?+

Chrome extensions that auto-bid on Writedom and WritersHub. Built by Cephas Nyamai Mutisya. Trusted by 600+ writers.

Which boards?+

Writedom and WritersHub. Each has its own extension on the Chrome Web Store.

How do I install?+

Add to Chrome, pin it, enter your licence, set filters, press Start Bidding.

Does it run 24/7?+

Yes, as long as Chrome is open.

Can I run both bots?+

Yes. Writedom and WritersHub are separate extensions. Install one or both, each with its own licence.

What if the bot does not start?+
