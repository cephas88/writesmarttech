Writedom Bidding Bot

A Chrome extension that watches Writedom and bids the moment an order matches your filters. You write. The bot stands in line.

  • Auto-bid on matching orders
  • Budget, type, and topic filters
  • Instant browser notifications
  • Runs in the background of Chrome
Get it on Chrome

WritersHub Bidding Bot

The same idea for WritersHub: live order monitoring and instant bids so you are not refreshing a board all afternoon.

  • Monitors WritersHub continuously
  • Smart order filtering
  • Instant bid placement
  • One-click setup after install
Get it on Chrome

  1. 01

    Add the extension

    Open the Chrome Web Store listing for Writedom or WritersHub, click Add to Chrome, and pin it.

  2. 02

    Enter your licence

    Open the bot, add your licence key, and set budget, order types, and filters.

  3. 03

    Start bidding

    Save, hit Start Bidding, leave Chrome open. Support for licences is by email.
