Installation Guide

Step 1: Extract the ZIP File

Once downloaded, locate the ZIP file in your Downloads folder. Right-click on the file and select "Extract All..." or use your preferred extraction tool. If you don't have an extraction tool, we recommend downloading WinRAR to extract the ZIP file.

Tip: After installing WinRAR, right-click on the ZIP file and select "Extract Here" or "Extract to [folder name]".

Extract the downloaded ZIP file using right-click menu

Step 2: Open Chrome Extensions Page

Open Google Chrome and navigate to the extensions page by:

  1. Type chrome://extensions in your address bar and press Enter, or
  2. Click the three-dot menu in the top-right corner → More tools → Extensions

Type chrome://extensions in your address bar

Step 3: Enable Developer Mode

In the top-right corner of the extensions page, toggle on "Developer mode".

Toggle the Developer mode switch in the top-right corner

Step 4: Load the Extension

Click the "Load unpacked" button in the top-left corner. Browse to the folder where you extracted the extension files and select that folder.

Click "Load unpacked" and select the extracted folder

Step 5: Pin for Easy Access

To pin the extension for easy access:

  1. Click on the puzzle piece icon in the top-right corner of Chrome
  2. Find the extension in the dropdown list
  3. Click the pin icon next to it

Click the pin icon next to the extension in the dropdown menu

Step 6: Configure and Use

Click on the extension icon in your browser toolbar to open the settings panel and configure according to your preferences.

Visit the respective platform (Writedom or WritersHub) and let the bot work its magic!
