Installation Guide

Step 1: Add Extension to Chrome

Click the "Add to Chrome" button above for your desired bot. This will take you to the Chrome Web Store.

Click the "Add to Chrome" button on the right top side of the Chrome Web Store page and confirm the installation when prompted.

Ensure you are using the latest version of Chrome for optimal performance.

Step 2: Pin the Extension

After installation, pin the extension for easy access:

  1. Click the puzzle piece icon in the top-right corner of Chrome
  2. Find the bot extension in the dropdown list
  3. Click the pin icon next to it to keep it visible in your toolbar

Step 3: Install RektCaptcha (Required for WritersHub Bot)

If you're using the WritersHub Bidding Bot, you'll need to install the RektCaptcha extension:

  1. Visit the RektCaptcha Chrome Web Store page
  2. Click "Add to Chrome" and confirm the installation
  3. No need to pin this extension, just open it, activate the settings of the rektcaptcha and set all timers to 0 for optimal performance
RektCaptcha helps handle CAPTCHA verification automatically for the WritersHub bot.

Step 4: Configure Your Bot

Click on the bot icon in your browser toolbar to access settings:

  1. Click start one time FREE TRIAL or activate the bot
  2. Configure your bidding preferences

Step 5: Start Using Your Bot

Make sure to save settings before clicking the Start Bidding button

Once you click the Start Bidding button, the bot will begin monitoring and bidding on available orders based on your settings.
